# Mini Projeto de Estatística

### Descrição e objetivo

Pequeno projeto pessoal de tecnologias ferramentas de desenvolvimento web.
O objetivo pricipal é aplicar os seguintes conceitos:
- Objetos e fechamentos
- ES6 módulos
- Uso e configuração:
    - gerenciador de pacotes `npm`
    - webpack
- Aplicação do algoritmo se ordenaçao Merge Sort
- TDD com uso do `Jest`
